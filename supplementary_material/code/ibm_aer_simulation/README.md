# IBM Aer Simulation

This directory contains ideal Aer circuit generation and execution for circuit-level references. The phenomenological noise parameter used by the protocol-batch Monte Carlo model is separate and is not represented as an Aer `NoiseModel`.

No IBM account is required. These modules do not submit hardware jobs. The three-Bell-pair composed candidate accompanies the direct `m=1` circuit-level evidence and is not a full physical-copy batch implementation.
